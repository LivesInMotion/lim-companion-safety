# LIM Companion Safety

Open, reviewed building blocks from [LIM Companions](https://livesinmotion.org/app), free AI companions by Lives In Motion Ltd,
for anyone building AI helpers for real people, especially in the UK and across Africa.

| File | What it does |
|---|---|
| `src/companion-safety.ts` | Fixed, reviewed safety replies for crisis messages (self-harm, abuse, emergencies) with real emergency numbers and helplines, plus money-hardship and malaria guidance. These replies are **not generated by AI**, so they are predictable and auditable. |
| `src/human-help.ts` | "Talk to a real person": free, local human services by country (UK, Ireland, Nigeria, Kenya, South Africa, Ghana, US), with a global fallback. |
| `src/lim-router.ts` | An on-device "front door" that routes a message to the right specialist (wellbeing, learning, money, work). Crisis messages always go to the wellbeing companion; needs we don't yet cover are flagged so they can be counted, never ignored. |
| `src/handoffs.ts` | "Do it in one tap": country-aware links into the person's own apps (rides, food, groceries, jobs, business registration, care, learning) so an assistant can help with everyday tasks without handling payments or logins. Never offered for crisis messages. |

## Principles

- **Human help first.** When someone is struggling, point to real, free, local people.
- **Fixed text for crisis moments.** Safety-critical replies are reviewed text, not model output.
- **Private by design.** Routing runs on the device; nothing here sends personal data anywhere.
- **No money handling.** Hand-offs open the person's own apps; they choose and pay there.

## Use

Plain TypeScript, no dependencies. Run the tests with Node 22+:

```
node --experimental-strip-types --test test/*.test.ts
```
